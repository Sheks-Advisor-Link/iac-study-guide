Trigger Quick-Fire — keyword → section → action

Read each fact in the scenario, fire the trigger, then write the full point (section → rule → apply → case → conclude).

Income & deductions

"foreign / emigrated / non-resident" → residence & source; s6quat; s9HA exit; DTA.
"free use / interest-free / barter" → amount = money's value (Brummeria/Lategan).
"deposit / advance / refundable" → received for own benefit (Geldenhuys/Pyott); maybe s24C.
"sold asset — capital?" → intention test (Pick n Pay/Natal Estates); CGT vs revenue.
"restraint / annuity / lump sum / lease premium" → special inclusion (par a–n).
"is X deductible?" → s11(a) 6 reqs + s23 (PE Tramways / New State Areas).
"prepaid" → s23H (≤100k / 6-mth provisos).
"before trade started" → s11A ring-fenced.
"legal fees / damages" → s11(c) + capital test.
"stock / obsolete / own use" → s22(1) lower cost-NRV; s22(8) deemed recovery.

Assets & companies

"manufacturing machine" → s12C 40/20/20/20.
"vehicle / furniture / PC" → s11(e) IN47 (apportion).
"new building — factory / office / flats" → s13 / s13quin / s13sex.
"solar / renewable" → s12B (100%) / s12BA (125% in window).
"repaired / renovated" → s11(d) repair vs improvement (Flemming).
"sold a depreciable asset" → ALWAYS s8(4) recoupment + CGT.
"lease premium / tenant must build" → s11(f) / s11(g)+par(g)/(h).
"dividend declared" → 20% DT; s10(1)(k); exempt owners s64F.
"return of capital / CTC" → not a dividend; reduce base cost (par 76B excess = gain).
"group restructure / for shares" → corporate rules s42/45/46.
"loss b/f + big profit" → s20 80%/R1m cap.

Specialised & admin

"loan / debenture / interest" → s24J accrual (s23B priority); s24O; s8F hybrid.
"forex debtor / loan / FEC" → s24I + s25D translation.
"paid tax overseas" → s6quat rebate.
"offshore sub >50%" → s9D CFC.
"connected cross-border price / mgmt fee" → s31 transfer pricing.
"debt waived / compromise" → s19 / par 12A (trace use of funds).
"employee shares / options vest" → s8C (remuneration on vesting).
"patent / IP / royalty" → s11(gC) (no TM); 15% WHT; s23I.
"SARS reassessed / penalty / object" → TAA s102/s104/s164/s222; 3-yr prescription.
"scheme solely to save tax" → specific AA first, then GAAR s80A.

VAT quick-fire

"vendor / supply" → output−input; std/zero/exempt.
"exported / going concern / brown bread, milk, maize" → zero-rated s11.
"interest / residential rent / school fees / public transport" → exempt s12 (no input).
"company car / staff entertainment / club subs" → input denied s17(2).
"imported goods" → customs +10% +duties ×15%.
"imported services (exempt use)" → self-account VAT on non-taxable %.
"fixed property sold" → s9(3)(d) timing (earlier of reg / payment).
"bad debt written off / recovered" → s22 input adjust / output back.
">R1m supplies" → compulsory registration (all branches s50).
